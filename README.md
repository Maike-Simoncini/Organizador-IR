# 📊 Organizador de Declaração de Imposto de Renda

Este projeto tem como objetivo criar uma ferramenta em **Excel** para organizar e reunir informações essenciais da declaração de imposto de renda. A solução foi desenvolvida com foco em **usabilidade**, **validação automática** e **navegação prática**, permitindo que o usuário controle suas entradas financeiras de forma eficiente.

---

## 🚀 Funcionalidades

- Cadastro de dados pessoais do titular (nome, CPF, endereço, etc.)  
- Registro de rendimentos bancários com anexos de comprovantes  
- Controle de entradas mensais (holerites, extratos, etc.)  
- Tabelas de apoio com códigos e nomes de bancos  
- Validações automáticas para evitar erros de preenchimento  
- Navegação facilitada entre abas  

---

## ⚡ Como Usar

1. Baixe o arquivo Excel dados_titular.xlsx.
2. Preencha seus dados pessoais na aba **Titular**.  
3. Insira os rendimentos bancários na aba **Informes**.  
4. Registre entradas mensais na aba **Notas**.  
5. Utilize as tabelas de apoio para validar códigos de bancos.  
6. Gere relatórios e utilize os anexos para complementar sua declaração.
